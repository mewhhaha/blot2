# Private source-bound scalar/loop runtime reservation

This scratch wrapper composes the existing independently checked U32→U32 typed scalar/finite-loop source arena and its `leaf_resource` summary with a real, fixed-memory Wasm preflight. Before assembly it rechecks the exact source, full leaf target and resource summary. It then emits a module whose only export is a private `invoke(i32)->i64`; the original callable and memory remain unexported. A separate target checker reconstructs and verifies the entire source-bound leaf, module sections and wrapper instruction sequence, including the exact declared depth/frame constants.

The selected fixture has one fixed 275-page memory. Its control words at 0 and 4 hold active depth and relative frame frontier; the independently checked metadata reserves the frame interval `[8720,1057296)` (1,048,576 bytes). Starting from private zero-initialized memory, the wrapper checks old counters and available space without unsigned overflow. Its conservative depth reservation is the source's advertised depth plus one wrapper level; frame reservation is the advertised source frame (the wrapper and checked leaf use no K1 linear frame slots). Depth is capped at 128. A failed preflight returns private packed status 2 (depth) or 3 (frame) before source effects and changes no memory. On normal execution it writes both actual in-memory counters, calls the source with zero environment, restores the exact prior frame and depth, and returns the U32 result in a success i64. Declared resource bounds are retained rather than silently narrowed to the leaf's inferred 1/0.

The trusted private instance is nonconcurrent, has no imports or host callbacks, exposes no raw memory or worker, and has a correctly provisioned Wasm engine. The source subset has no user calls, aggregates, memory instructions, captures or backing allocation. An unexpected Wasm trap is not recoverable cleanup: the counters may remain reserved, and the host must poison and discard the entire instance. This scratch code does not itself implement a public host wrapper or sticky poison state. Test-only binary instrumentation exports memory solely for observing counters and proving failed preflight makes no memory change and normal returns restore it; this instrumented module is not an accepted target or authority.

O0/O2 tests run `leaf_runtime_test.goose` in a fresh cwd followed by `node /tmp/k1-leaf-runtime/test.mjs`. They cover source/summary forgeries, every target byte mutation/truncation, normal and exact-fit reservation, both exhaustion classes and malformed frontiers, zero-frame loop/edge inputs, excessively large declared source bounds, full-memory preflight failure and normal-return equality, and a type-valid test-only source trap. The trap control confirms exhaustion paths do not call source and that a real trap leaves counters live and requires discarding the instance.

This is a narrow fixed-profile runtime witness, not general K1 call-graph resource composition, frame-layout proof for aggregate/closure/callee slots, public scalar ABI/manifest/hash, host engine stack bound, source ownership/loans, C09, M11 qualification or compiler speed claim. Fixed control-word ownership and source memory isolation rely on the private instance and the independently checked target subset, not caller-supplied numeric capability IDs.
