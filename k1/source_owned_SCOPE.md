# Private source-derived Owned contract witness

A single private function is accepted with a fixed declared `type Scalar[r: Region] = U32`, tuple parameter `(Owned[Scalar[_]], Bool)`, one of Unit/U32/Owned results, and an explicit `{release}` effect upper bound. The source parser extracts the actual tuple binding names, result and entire body. A separate source replay independently checks those fields, then runs the existing bounded lexical ownership checker on the exact body and inferred contract. `admit` publishes no candidate on failure. `run` rechecks the entire caller-supplied expected source before using the existing native ownership runtime.

This removes a caller-supplied owner name, flag name, payload scalar assumption and return mode for this one source form. It supports no arbitrary type declarations, other payloads, general interfaces, function calls, globals, source-generated Wasm or canonical aggregate ABI; it is not an admitted complete K1 compiler. It does not establish actual resource bounds or C09. The native witness assumes a compiler-private, non-copied live runtime State/Clock and authentic handle, no concurrent mutation of source or state, and the existing fixture allocator semantics. It does not authenticate untrusted handles or prove host/engine cleanup after traps. The producer `build` performs syntax extraction only and is not an admission API: use `admit` or independent `verify` before using a record. No OOM atomicity is claimed.

The native runner delegates to the existing `ownership_runtime` conservative counter preflight. It rejects when `stamp > 18446744073709551487` or `next_loan > 18446744073709551359`, even when this particular source would not perform enough moves or openings to exhaust a counter (including the open-free Unit example). This preserves state on rejection but is not complete acceptance near those limits; no claim is made that these fixture counters are K1 runtime resources.
