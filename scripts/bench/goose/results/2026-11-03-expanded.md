# Seven-case Goose survey

The survey now attempts all seven adapted Goose LangArena cases. **Four pairs
retain the original numeric workload; one additional pair is an explicit F32
Mandelbrot control.** Two recursive sorting ports fail to compile in Blot.
Original F64 Mandelbrot remains unavailable. The other 43 catalog tasks have not
been adapted in Goose.

No compiler was rebuilt or changed. Blot remains `89cd47f3…` and the frozen
Goose comparator remains `353a3f1b…`, with Node 24.22.1 / V8
13.6.233.17-node.58. Every original three-case Wasm artifact still matches the
preceding [fixed-span checkpoint](2026-11-03-fixed-spans.md) exactly. New timing
differences on those cases are fresh shared-host measurements, not compiler
improvements.

Five matched fresh-process pairs, after one discarded process warmup, retain
production problem sizes with explicitly reduced repetition counts. All emitted
programs pass their checksum and revision checks. Exact samples, source and
binary fingerprints, diagnostics and controls are in
[the evidence](2026-11-03-expanded.json).

The new cases expose these hills:

1. **Owned-storage recursion.** Both original recursive sorting algorithms fail
   with `storage_unsupported`: “Recursive selected calls are not supported by
   the owned-storage backend.” Their source ports preserve full copies, merge
   temporary clearing and warmup/RNG state. They are compile probes, with Blot
   runtime correctness still unqualified. Enabling recursive/reentrant owned
   function plans would unlock two whole benchmarks.
2. **CRC32 and custom hash remain the largest measured gaps.** The preceding CRC
   source controls support a bounded shift/XOR recurrence fold. The custom hash
   still retains all eight lanes and the complete digest; profile its remaining
   scalar/index work before selecting another optimization.
3. **Sieve's wider flags explain only part of its gap.** In a separate
   five-round matched control, Goose U8 flags take 19.88ms, Goose U32 flags
   26.50ms, and Blot U32 flags 61.23ms. Matching element width still leaves
   about 2.3x. Profile filling, marking and scanning before choosing bulk
   operations or bounds proofs. The first U32 control exhausted Goose's original
   16MiB limit; the final pair rebuilds both Goose variants with the same 64MiB
   maximum. No generated Wasm was patched. The failed attempt remains unscored.
4. **Mandelbrot has a small, measurable constant-expression hill.** Replacing
   only its two `2.0 * 2.0` expressions with `4.0` changes 96.62 → 74.42ms
   (1.297x paired speedup). Replacing all F32 arithmetic/comparison operators
   with primitives gives 74.35ms (1.304x). The literal-only change captures
   nearly the entire observed gain. This supports investigating constant
   propagation and V8 inlining decisions; it does not prove that all forwarding
   calls cause the gap. The reported port keeps the original expressions.

Mandelbrot's original F64 semantics are deliberately separate. An actual native
probe rejects an F64 annotation with `unsupported_type`. Both measured sources
use ordered F32 operations and retain every PBM image, including headers and
warmups. The independent Python model rounds after every operation. At the
production dimensions/counts, F64 checksum is **3455988829** and F32 checksum is
**3340890973**, so narrowing the original and claiming equivalence would be
incorrect. The explicit Goose control is tracked beside the Blot port.

Sieve flags and retained PBM bytes use Blot U32 versus Goose U8, four times the
element payload. Sorting values are nonnegative U32 versus Goose I32, preserving
ordering. Its exact integer RNG conversion matches every Goose RNG state for
sizes 100,000/400,000 and preparation maximum 1,000,000; the ports explicitly
reject other sizes. Floating rounding differs for some other legal Goose sizes,
and those counterexamples are retained. The custom hash is not cryptographic
SHA-256. ABI costs differ; V8 is the only measured engine.

Qualification is **partial**, matching the visible failures: 120 successful
build samples, four failed build samples across two sorting cases/phases, 24
successful checksum/revision qualifications and 144 successful runtime
invocations. All original official checksums match the independent oracle; three
oracle tests also cover padding, retained warmups and F32/F64 divergence.
TypeScript checks, Ruff and formatting pass. Existing compiler-wide
qualification remains unchanged; this survey makes no broader language or
runtime qualification claim.

Goose also has integer recurrence, indexed updates, recursive Fibonacci and F64
recurrence fixtures. They remain unported here: the first two use wider
intermediates, and the others exercise the recursion/F64 gaps above. They are
listed as future coverage, not failed or passed measurements.
