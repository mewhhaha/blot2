# Private source/target-bound caller operation proof

This experiment constructs a proof from the actual last function body of the existing private `m12_internal` Wasm target. The target is independently checked against the retained exact adapter/kernel source and the pinned one-module base before the body is decoded. The proof owns exact source/target bytes and records source-bound machine call positions, argument-local origins, control nesting and input/output byte-copy positions. A separate consumer re-decodes those instructions and verifies the retained evidence; changing the source, target, operation site, helper, branch parent or proof fields fails.

The closed checker validates the source-checked adapter/worker target and the fixed helper sequence: frame configure/entry, reservation, reservation-failure frame leave, input allocation/copy/freeze, exclusive builder allocation, the exact adapter call, output copy, output-view end, input-view end, owner close, frame leave and final header publication. It verifies the reservation-failure leave is inside the `owner <= 0` branch, helper error checks trap instead of continuing, the same slot/generation locals feed every transition, the adapter's fixed slots receive the placed input and output, and the copy and publication instruction segments are the reviewed fixed ones. Local abstract states record the success path's frame, owner, uninitialized input, frozen input, exclusive builder and result-view transitions; the reservation-failure branch has a separate frame-only exit. These bit labels are proof bookkeeping, never a runtime capability or bearer identity.

This is a **fixed, source-bound machine witness**, not a general K1 borrow/affine/effect checker or an independent semantic proof of all helper implementations. It relies on the separately reviewed, exact source/target and runtime helper byte pins, their intrinsic contracts, a private nonconcurrent memory/instance, and the absence of externally forged raw helper calls. It does not infer actual ownership from matching numeric IDs. It does not prove the declared 1024/768 frame geometry is sufficient for a complete program, authenticate a public M12 manifest/ABI, close C09 accounting or qualify arbitrary host loans. `m12_adapter_verify::public_eligible` remains false.

On normal return the caller closes its tracked descriptors and owner and leaves the frame before publishing the output header. A test-only unexpected trap can occur after egress payload bytes were copied; no new result header is published and Busy stays set, but old header/payload bytes can remain or change. The host must discard the instance; this proof does not establish general trap cleanup or a recoverable source error.
