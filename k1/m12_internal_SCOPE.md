# Private source-linked in-module caller witness

This scratch fixture appends one fixed `invoke(export_id,input_bytes,output_capacity)` Wasm function to the independently checked one-module adapter and particle worker. The compiler-side emitter takes the exact source-checked `m12_adapter` Program and verifies the existing target before composing it. A separate fixed-byte target checker rechecks the source, the independently checked base module and every new section/body byte; it is a pinned witness, not a general Wasm or ownership validator. The test module has no imports, but retains raw memory and setup/helper exports for private inspection.

The invocation uses fixed private 256-byte ingress and egress windows at 32768 and 36864, Busy word 416, and export ID 91. It validates the full header, source-field order (View descriptor followed by F32), offset, count, alignment, extent and zero padding before entering its fixed frame. It creates the owner internally, copies input into its freshly allocated region, freezes the initialized View, allocates the disjoint output builder, calls the exact in-module checked adapter once, copies an Ok result while both backing loans are live, then ends both descriptors, closes the owner and leaves the frame before publishing the final header. The in-module setup never accepts an external owner, region, domain or descriptor as a capability. The source's two distinct formal Region IDs are not used as disjointness evidence; checked placement and the private runtime state establish the fixture's same-owner geometry.

InvalidInput, Busy, OutputTooSmall, FrameLimit and reservation errors are tested. Busy changes no bytes. InvalidInput and OutputTooSmall do not publish output payload; the required output size is computed after the single source call. Tests also alter the target only to inject reservation/frame/partial-worker failures: those altered modules are not accepted by the source/target verifier. Any unexpected Wasm trap is a poisoned invocation. **A trap after result copying may leave changed egress payload bytes even though the final header is not published.** A header from an earlier call can remain in memory. The host must discard the entire instance and must not treat the trap as a recoverable K1 `#Err` or inspect that stale header. This fixture does not prove general trap cleanup.

This remains a private fixed-shape witness, not M12/public eligibility. The raw fixture exports and linear memory are trusted and must not be accessible concurrently to an untrusted host. The fixed 1024-byte configured frame and 768-byte reservation are not independently qualified as the complete source/adapter/host frame bound. The source language still lacks a general typed compiler-owned capability/loan Core and verified intrinsic lifecycle, general source effects, manifest/ABI identity and canonical public windows, frame/depth composition, complete F32 NaN qualification, and declaration-wide C09 accounting. Matching numeric IDs or a byte pin alone are not general ownership authority. `m12_adapter_verify::public_eligible` remains false.
