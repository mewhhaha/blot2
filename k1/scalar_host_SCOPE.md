# Private source-bound scalar host policy experiment

This is a fixed experimental Bool→U32 scalar host policy, **not a resolution of the unspecified public scalar ABI**. A separately checked `generic_bool` source declares `depth: 1, frame: 0`; the independent scalar target checker validates its complete body, source association, no imports and no memory-access/call instructions. The scratch emitter adds one private Wasm wrapper, removes the raw scalar export, and independently checks the entire assembled module including the scalar target and a separately pinned wrapper body. It accepts only that depth/frame profile, so otherwise valid widened declarations are deliberately rejected.

The chosen wrapper entry `invoke(raw_bool:i32, depth_available:i32)->i64` is private: raw Bool must be 0 or 1; otherwise return `(1 << 32)` without calling source. Next, require the caller-supplied unsigned depth budget in `[2,128]`, or return `(2 << 32)` without calling source. On success call the verified scalar with environment zero and return status 0 in the upper 32 bits and the U32 result in the lower 32. Invalid Bool takes priority. The extra depth unit conservatively treats this private wrapper as one additional callable; no K1 linear frame bytes are used by the wrapper or independently checked leaf, so zero frame bytes trivially fit. The depth argument is a host assertion and does not authenticate engine capacity or prove a general M11 envelope.

`scalar_host.mjs` is a private Node host for the one separately source-checked canonical fixture, with embedded complete target bytes. It snapshots untrusted target bytes using trusted intrinsics, rejects mismatches, instantiates a private module with no memory or raw callee export, accepts primitive unsigned integer arguments without coercion, and returns copied `{status,value}` objects. A Wasm trap or impossible result poisons that host object permanently; it is never retried. A separate test-only temporary host copy pins a deliberately trapped source body to test poisoning without weakening the ordinary pin.

The Goose test emits and checks two distinct valid sources at O0/O2, rejects source and resource forgeries, widened unsupported profiles, every target byte mutation and all truncations. Node verifies canonical Bool/results, invalid Bool, depth boundaries, priority and export isolation. A test-only type-valid source trap establishes that invalid Bool/depth checks happen before the source call; the pinned host rejects that altered target, while its temporary instrumented copy proves trap poisoning is sticky. Target/host checks assume trusted JS/Wasm intrinsics, nonconcurrent source bytes while initially copied and a properly provisioned engine.

This fixture does not specify or qualify a public host ABI, manifest/hash, general resource or effect checker, general M11, C09, installed CLI, scalar types beyond Bool→U32, or runtime speed. The internal source callable alone is not a public ABI. The user-provided depth number is not authority and cannot substitute for the host engine envelope or a verified deployment manifest.
