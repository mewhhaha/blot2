# Private cross-module scalar call-chain fixture

This private bounded experiment accepts up to 16 root entry declarations and one public declaration per imported module. Each declaration is either a U32 scalar leaf (identity, constant or bitwise AND) or one direct qualified call to another module. It checks the entire source-owned import graph for cycles, independently recognizes each original wrapper header and call, resolves each receiver within its actual module, and decodes the exact source-derived package/module/name/ABI/type/resource interface associated with the selected callee. Positive and negative observations include the querying module and exact alias, member and producer path. All declared frames must be zero; a wrapper's declared depth must exceed its callee's declared depth, and the root adds one. This is not general K1 typing, full project admission, full compositional resource validation, a qualified host ABI, or complete C09/work accounting.

The canonical public interface encoder currently accepts a scalar leaf candidate. For a wrapper only, the experiment constructs a synthetic identity body with the same declaration header to encode its signature; it independently recognizes the original source and actual call, verifies the synthetic candidate, and independently decodes the canonical package/module/name/ABI/type/depth/frame envelope. The synthetic identity body is never used to prove the actual call, the wrapper body or target instructions. The caller supplies the 32-byte ABI identity.

The emitter creates one direct Wasm function per module plus root wrappers, with fixed 275-page memory and no imports. A separate target checker rederives the source graph and call plan and checks all target bytes, including each call index. Revalidating a supplied graph does not authenticate its filesystem origin. Reads through the trusted live root descriptor are sequential and do not provide a coherent mutable-filesystem snapshot; the descriptor must not be copied or closed concurrently. Unsupported resolver platforms fail closed.

The sequential compiler-owned revision session rereads, rechecks, recompiles and validates every update; it performs no compile skipping. The exact semantic interfaces can remain unchanged across a body edit while target bytes change. Checked synchronous failures preserve the last successful generation, including negative member lookup results on failure. `current` revalidates retained bytes against retained source and returns a historical generation, not a statement about the present filesystem. Eight generations may be retained; subsequent successful updates can return fresh unretained bytes. Recoverable OOM, async cancellation, concurrent operation, disk artifact authority and full host runtime stack/ABI qualification are outside the experiment.
