# Private fixed caller helper checks

`m12_helper_source_test.goose` source-checks and emits the guarded in-module caller, builds its existing source/target-bound caller-flow evidence, and separately does the same for an alternate source expression. It writes `private-invoke.wasm` and `alternate-invoke.wasm`. The Node audit first requires the independent exact canonical target pin and decoder. For an alternate target it additionally compares every decoded instruction and immediate in the common allocator, descriptor, frame, adapter, shim and caller functions to the pinned target. This Node check must be run after the Goose source/target test; instruction equality by itself does not authenticate arbitrary source.

`m12_helper_structure.mjs` recognizes selected actual Wasm guard and return sequences. The owner slot and generation tests precede slot addressing; allocator/freeze/builder overflow and extent checks precede their first stores; project checks owner and descriptor state, both extents, same-owner non-overlap and count/capacity before its single worker call; end/close check descriptor state and generation before transition. Negative test mutations independently exercise these patterns. This is a fixed instruction-shape witness tied to the separately pinned target, not a general control-flow or Wasm verifier. It does not independently prove every helper instruction, worker semantics, all path dominance, global bitmap disjointness or engine behavior.

Executable tests invoke the actual target's private helpers on canonical and alternate artifacts. They exercise counts 0–8, stale and invalid owner/generation handles, allocation overflow/no-space, geometry and descriptor forgeries, overlap, unended descriptors, too-small capacity, double end/close and empty-view canonicalization; the main owner execution matrix uses slot 1. `m12_helper_slots_test.mjs` independently exercises all four owner slots and counts 0–8, while `m12_helper_slot_controls_test.mjs` also demonstrates the freeze-initialization premise. Failing operations are checked against full-memory snapshots. These finite tests provide evidence, not proof over all possible states. In particular `input_freeze` checks descriptor geometry but does not prove that bytes were initialized: initialization and scoped exclusivity are supplied by the checked caller's copy sequence and private runtime assumptions.

All raw exports and mutable memory must remain hidden inside a private nonconcurrent instance. Neither a slot, generation, pointer, record nor decoded proof is bearer authority. The fixture still does not establish a general source-level ownership or loan checker, public M12/ABI admission, complete M11 frame bounds, or declaration-wide C09. On any unexpected trap the host must discard the instance; egress payload may already have changed while its header is unpublished. No general trap-cleanup guarantee follows.
