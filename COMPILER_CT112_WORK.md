inference regions and 502,185 solver nodes in CT111's body-edit profile.

complete query validates and all publication capacity is reserved. Ordinary
typed views and bare imported values gain no authority.

consuming the selected result again to start zero inference regions. Changed

old-owner destruction remain required boundaries. This is one completed-result
family, not completion of reusable elaborated bodies or the full five-part

existing portable schema intentionally omits these extra claims: restart still
rechecks nested closures. There is no change to language syntax or to acceptance
of open effects, captures, source changes or low quotas.
