# Private checked multiline imported-leaf lift

This scratch extension accepts an original resolver-owned import graph and lifts a terminal no-import public multiline U32→U32 leaf whose independently source-replayed semantic Core is exactly one parameter return or one U32 literal return. A private synthetic one-line scalar module is created for the existing bounded chain compiler. The separate checker replays the original semantic-owner source and compares its exact declaration, U32 signature, effect-free source, declared depth, zero frame and result value against an independently parsed synthetic scalar Core. It separately verifies both graph structures and unchanged paths/import edges. Existing chain validation binds every source call to a unique checked producer and validates the emitted machine target against the synthetic Core. Synthetic text is a private intermediate, not evidence of original source authority. Equivalence is only claimed for these two result shapes; other multiline bodies fail closed.

The live root/package mapping, requested module/name, opaque 32-byte ABI and capacities are trusted private inputs. The single-module branch checks ABI length only and does not use or authenticate the ABI value. The source graph is read sequentially and is not a coherent mutable-filesystem snapshot; no concurrent root close or graph/source mutation is permitted. Confinement depends on the existing resolver and trusted hardlink/special-file root policy. The resulting Wasm does not uniquely encode original source bytes. A whole source revision can differ in irrelevant spelling while remaining semantically equivalent; dependency receipts, cache invalidation and persistent original-source certificates are not implemented. Depth comparisons are compile-time only, the call graph/ABI is a narrow U32 fixture, frame is constrained to zero and no runtime resource preflight, public ABI, M11, C09, general effects or general compiler implementation is qualified. Host OOM, arbitrary interruption, engine traps and atomic output I/O remain outside scope.
