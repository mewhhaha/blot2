# Blot case studies

These projects exercise Blot with real hosts, rather than defining additional
language syntax in examples that do not compile.

- [ECS 3D sandbox/editor](ecs/README.md): Deno Desktop/WebGPU presentation,
  Blot/Wasm systems, immutable ECS worlds, and live source/asset replacement.

Compiler fixes belong in `compiler/`, reusable source functions in `std/`, and
application-specific code and evidence in the case-study directory.
