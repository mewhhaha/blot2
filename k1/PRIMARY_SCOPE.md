# Private source-owned scalar arena compatibility

`short_parse` and independent `short_verify` accept a single `return` after `fn x =>`, replaying its original source tokens and lexical binding directly into the existing mixed arena. Other one-line statements, multi-statement bodies, mismatched types, unsafe checked arithmetic and nonempty effect rows remain rejected. `short_legacy_wasm` derives the prior simple U32 predicate target from the source-verified arena, and independently validates the resulting plan against source and target.

`primary_dispatch::compile` is a private opt-in entry, not public CLI admission. The previous checked dispatcher runs first and its successful result is returned unchanged. After a previous failure, the entry replays the six source frontends used by that dispatcher. If any recognizes the source, it returns the previous error and publishes no fallback; otherwise it attempts the independently checked new arena. Source must remain immutable throughout repeated checking. This prevents a reported previous emission failure on a recognized source from becoming another published target. Actual Goose host OOM can terminate the process and is not modeled as a recoverable error.

On the fallback, source-checked simple-predicate projection, plan, validation-configuration, emission and target-validation failures return an error without output; an independently validated legacy-source mismatch can use the checked modern target. The fault tests inject these stages and old-path failures. O0/O2 source/target mutation controls, a 435-source corpus, an independent 104-case matrix and six-frontend replay controls passed. These are finite samples, not complete syntax, status or target-byte parity. The unqualified resources, effects, ownership, public ABI, M13 and C09 boundaries remain; no compiler-wide performance claim follows.
