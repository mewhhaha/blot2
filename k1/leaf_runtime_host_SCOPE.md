# Private source-pinned leaf runtime host and trap disposal

`leaf_runtime_host.mjs` is a **private fixture**, not a public K1 ABI. It accepts one of four fixed source-gated targets generated by the existing Goose `leaf_runtime_test.goose`: identity with declared depth 3/frame 12; bounded scalar loop depth 1/frame 0; identity with frame U32_MAX; and identity with depth 128. The exact full target bytes for each source are embedded separately. The host snapshots the supplied Uint8Array using trusted built-in typed-array operations, compares all bytes to the selected pin before instantiation, and requires no imports and a sole `invoke` function export. Source code authority still comes from the separate Goose source/target gate; a byte match alone is not a general source certificate. The host constructs its pinned module and instance with captured synchronous Wasm constructors and returns a null-prototype host, preventing post-import Object.prototype.then from substituting the async create result. The JavaScript realm and its intrinsic implementations must be trusted at module initialization; target bytes must not be mutated concurrently during the initial copy. The host captures its security-relevant typed-array, invocation, integer, freeze and Wasm introspection intrinsics at initialization, uses indexed byte comparison, and tests later prototype/function tampering. This is not a guarantee against a realm already compromised before initialization.

Each returned host owns its own private Wasm instance. It accepts only primitive unsigned U32 numbers without coercion; an invalid argument returns `InvalidInput` without source execution. The source-checked Wasm wrapper preflights actual private depth/frame counters before the checked scalar call and restores them on normal return. Success becomes a fresh `{status:'Ok',value}`; private statuses 2 and 3 become `DepthLimit` or `FrameLimit`, with zero error payload required. Unexpected status, impossible error payload, engine exhaustion or any trap permanently poison the host and drop its only instance reference. Every later call returns `Poisoned`, without retrying source or switching runtimes. Dropping a reference does not promise immediate garbage collection or recoverable affine cleanup. The host does not expose memory or the raw callee.

The separate Goose gate rejects source/summary/target forgeries. Run `leaf_runtime_test.goose` at O0 and O2 in isolated cwd, then `node /tmp/k1-leaf-runtime/test.mjs` and `node /tmp/k1-leaf-runtime/leaf_runtime_host_test.mjs`. The first test separately instruments a test-only memory export and source trap: it proves capacity failure before source and demonstrates that a post-reservation trap leaves depth/frame counters live. The host test covers all four source pins and full byte mutation/truncation, cross-source mismatches, copied target snapshots, invalid/hostile JS inputs, post-import intrinsic tampering, normal/depth/frame statuses and output isolation. A temporary test-only copy of the host substitutes the pinned bytes with (1) a type-valid source trap and (2) a type-valid impossible-status mutation; the ordinary host rejects both, while the temporary copies demonstrate sticky poison and no retry.

This does not establish public scalar host convention, manifest/ABI hash, general source ownership, arbitrary source call graphs, aggregate/closure frames, typed trap cleanup, C09, engine stack capacity, full M11 qualification or speed improvement. The fixed private module has one nonconcurrent instance and no callbacks; callers cannot infer capability authority from scalar values or statuses. Host/JIT stack provisioning is still a deployment assumption.
