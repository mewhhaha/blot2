# Private common scalar Core prototype

One source-bound `unified_core::Program` represents U32 or Bool input and U32 or Bool result for a single private `let NAME: A -> B = fn PARAM => do:` declaration. The frontend and independent shape recognizer reconstruct parameter and result types from source and check each node, lexical U32 binding and return. Proof production and separate evidence replay use numeric checking for U32 results and short-circuit branch checking for Bool results. Bool parameters carry no numeric range evidence. The private target decoder checks the exact source, Core and emitted scalar Wasm instructions before return.

The Bool input is an i32 and callers must supply 0 or 1; the target does not authenticate that precondition. Locals are U32 only; loops, calls, complex types, effects and resources, public-shaped declarations and the wider language are not supported. These files are isolated copies of existing scalar machinery, not yet a replacement of shared dispatch or a common IR for finite-loop variants. The limited status and byte differential suite establishes sampled parity, not complete equivalence. This experiment does not establish public ABI, ownership, M13 or complete C09 qualification.
