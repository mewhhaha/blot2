# Private multi-entry linked scalar fixture

This experimental slice checks at most 16 source-owned entry declarations, each returning one direct qualified call to a public U32 scalar provider. It can select multiple providers from multiple imported modules. The accepted provider bodies are identity, a constant, or bitwise AND; each selected provider must declare depth below 128 and frame zero. This is not a general call graph, full K1 frontend, project compiler, qualified ABI, or complete C09/work accounting implementation. The 32-byte ABI identity is supplied by the caller. Optional member probes conservatively reject shadowing by any checked entry's name or parameter.

Each update reads a bounded graph using the existing trusted live root descriptor, checks graph/import/source and exact public interface identities, records ordered positive and negative member observations, then regenerates and validates target bytes. The source-owned plan includes the full read graph and its provider bodies. The separately checked target has one provider and one direct-call wrapper per entry, no imports, and fixed 275-page memory. These checks validate a supplied in-memory plan and complete target; they do not authenticate the supplied graph's filesystem origin. Reads are sequential and do not provide a coherent filesystem snapshot; the root must remain live and must not be copied or concurrently closed. Unsupported source resolver platforms fail closed.

Revisions are sequential and compiler-owned. An update always rebuilds and rechecks; there is no compilation skipping. Interface dependency equality can remain true after a provider body changes while target bytes change; a missing member becoming present changes semantic identity even if the target stays identical. Failed updates preserve the last successful generation on the synchronous checked paths. `current` revalidates retained source and target but returns a historical generation, not a fresh filesystem assertion. At most eight versions are retained, after which fresh successful bytes are returned without retention. Atomicity under recoverable OOM, asynchronous cancellation, or concurrency and disk artifact authority are not claimed.
