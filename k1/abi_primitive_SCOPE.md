# Private source-linked primitive ABI schema fixture

This bounded experiment encodes four builtin semantic types, Unit, U32, F32 and Bool, as machine-readable fixed records with representation size/alignment, dictionary flags, value-validity category, scalar machine representation and the generic-indirect convention. An independent decoder checks the whole 40-byte record against the builtin selected by the trusted compiler request; neither a numeric ID nor the record alone establishes identity. The format and numeric tags are explicitly private candidate identifiers, not the canonical K1 ABI serialization.

`abi_primitive_link` independently re-recognizes the exact generic-identity source, reconstructs the expected builtin dictionary, validates dictionary fields and complete identity, and invokes the existing independent exact source/target Wasm verifier on the actual emitted target. The same one-body worker is tested with all four dictionaries; Node verifies zero-size behavior and exact U32/F32/Bool byte copying, including signed zero and NaN payload bits. Input validity (e.g. Bool 0/1), dictionary memory protection, initialized/exclusive slots, ownership and loans are trusted caller obligations; this fixture does not manufacture or validate those authorities.

The bundle additionally binds the existing provisional policy digest, whose record inventory is incomplete; the digest is not the qualified M10 hash. No public ABI, interface/implementation/manifest/certificate authentication, full source-language type checking, generic layout reasoning, work receipt, memory-frame or M13 proof follows. `public_eligible` is hard false. Unknown builtin codes and all incomplete types, operations, layouts or artifacts fail closed. O0/O2 tests reject all byte flips in source/schema/dictionary/target/policy hash, every schema truncation, wrong builtin type and forged dictionary geometry, plus execute the actual target. Trusted intrinsic/runtime and nonconcurrent memory assumptions remain explicit.
