# Private source-associated bridge Core and fixed-target lowerer

The source adapter/kernel are independently validated first. The compiler then constructs a closed bridge Core, retaining its exact source and source-event sites, thirteen resource operations, and all nine guarded input-count cases. The independent Core verifier rechecks the source and replays a scoped owner, frontier Space, initialized-input destination, immutable input loan, exclusive output destination and returned output loan. The Core includes an explicit `space.end` after both loans end and before owner close. It also checks the reservation-failure branch creates no owner or Space. The verifier derives input/output extents from the fixed 192-byte region and capacity 8; no caller-supplied slot, generation, range, site or domain integer grants authority.

`bridge_plan_emit::emit` requires successful source/Core replay before producing any target. It processes every checked Core operation, emits the corresponding fixed Wasm call or zero bytes for erased logical markers including `space.end`, and independently validates the complete resulting source-bound target. It scans the fixed caller instruction template, assembles a fresh module around its checked base, and never emits a full reference caller before Core verification. Its fixed machine template contains the checked caller's intervening validation, copy loops, return paths and publication bytes. It is not a general Core instruction selector: those intervening bytes are taken from the independently pinned fixture, not derived from arbitrary Core. The source adapter itself remains an exact closed-token recognizer; the worker is a bounded source subset. Proof records are mutable evidence, not runtime capabilities, and raw helper exports and writable memory must stay hidden in a protected nonconcurrent instance.

The verifier models an explicit Core Space.end rather than assuming that a raw owner close consumes Space. Its source associations and runtime behavior remain conditional on the separately checked fixed helper contracts, source-local affine proof and initialized-copy/range obligations. For empty input the copy-completion marker precedes freeze even though no loop store executes; for OutputTooSmall result handling completes without publishing payload before loans end. Unexpected traps still poison the invocation and require discarding the instance; a stale header or partially changed payload may remain. General source ownership and loans, public host capability authentication, ABI/manifest qualification, complete frame/depth/M11, declaration-wide C09 and arbitrary compiler-generated calls remain unproved. `public_eligible` stays false.

`bridge_plan_test.goose` builds the Core before emission and executes the emitted target through the existing private Wasm oracle. It rejects a missing, duplicated or reordered Space.end; every changed Core operation, source event or range field; wrong source and reuse of a proof for a different valid source. Run at Goose O0/O2 in isolated artifact directories, followed by `m12_internal_oracle_test.mjs` and `m12_internal_cleanup_fault_test.mjs` from the same directory. `bridge_plan_sites_test.goose` additionally rejects every template truncation and all changed call operands. Those tests are not public M12 or compiler-completeness qualification.

In the scratch integration, the existing private `m12_internal_emit::emit` entry now constructs a source-associated bridge plan and invokes the Core-checking lowerer; it has no separate direct-emission path. This routing affects the fixed private caller entry only. Internal template/helper modules still exist and must not be treated as a public admission API, and all earlier source, runtime, ABI, frame and accounting limits remain in force.
