# Private typed scalar/loop dispatcher

`typed_dispatch::compile` wraps the existing `common_decl_dispatch`: it always runs the old dispatcher first and returns any success byte-for-byte with its original argument/result/status fields. Only an old rejection can reach the source-bound typed canonical U32 scalar/finite-loop arena. The new branch independently checks the original source and its typed arena, emits through the typed canonical target path, and requires that path's independent target decoder before returning bytes. If parsing the additional subset fails, the prior rejection and status are returned. An unexpected validated-source/target failure reports an error and publishes no bytes.

This is a private opt-in function, not a change to public CLI commands or the existing dispatcher. It accepts a narrow checked U32->U32 public-shaped declaration subset; the fixture's boolean locals within loop bodies can express programs the older dispatcher rejected. Scope and exact resource declarations, retained artifacts, ownership, real ABI and complete C09/M11/public K1 are not qualified. The old-first double checking on a miss is not a speed optimization.

O0/O2 tests compare old success status, argument/result and exact target bytes over 128 signature/body cases; rejected cases preserve the old status unless newly admitted. Two previously rejected Bool-local carry/stop loops now generate independently checked targets, which Node executes for boundary values including U32 max with bounded early exit. Single-byte target mutations are rejected by the underlying target checker. Shared files and the test script are untouched.
