## 1. Problem Statement & Core Architecture

Squid's current concurrency prototype is fragmented across four disconnected, unused layers:
1. `@spark #[... | x <- xs]` ([parser.goose](../compiler-goose/src/parse/parser.goose#L984-L1042)) is parser sugar into `@array.generate` (0× speedup, rejects infix operators/captures/branches/helpers, misuses `@`).
2. `@spawn Start prog cfg` ([parser.goose](../compiler-goose/src/parse/parser.goose#L1056-L1084)) runs single-threaded cooperative turns via a single-file raw token scan for `_step`, limits state/cmd/reply to one `U32`, uses raw `U32` endpoints, and lacks revision fencing.
3. Parallel host execution is split across three incompatible, unchecked implementations: Deno [SparkPool](../host/sparks.ts#L133), Pen one-shot sandbox-per-job [Workers](../../pen/crates/squid-host/src/workers.rs#L41), and Pen/Ink magic-float [worker_sessions](../../pen/crates/squid-host/src/worker_sessions.rs#L103) / [worker_session.sq](../../ink/lib/pen/worker_session.sq#L9-L61) (`-4670546.0`, `-4670547.0`, `-4670545.0`).
4. Both hosts suffer from copy amplification, inaccurate `numericPacketCapacity()` under 64 KiB on-demand memory ([host/guest.ts](../host/guest.ts#L2246-L2263)), permanent pool degradation on single errors in Deno, and zero production adoption.

### Target Architecture (Three Orthogonal, Honest, Compiler-Verified Primitives)
1. **`spark #[expr | pat <- source]`** — Synchronous, pure, ordered data-parallel array map with compiler-verified context-sensitive relational read-only purity (§2.5). Auto-vectorizes to **4-wide Wasm SIMD (`v128`)** for eligible numeric/range-affine-stream kernels and compiles to a preallocated direct loop otherwise.
2. **`entry kernel`** — Pure, compiler-verified multi-core batch kernels (stateless or with a once-per-revision `prepare` step building arbitrary persistent owned data such as Gdev's multi-array `RouteContext`), backed by a unified **warm, work-stealing `KernelPool`** in Pen (Rust) and Deno/Web (JS/TS), discovered and schema-validated via the optional ABI 8 custom section `squid:kernels`, and bridged to live local games via Pen's recorded `service::KERNEL = 15`.
3. **`entry process`** — Isolated, persistent-state sequential actors (`init` + `step` with `own State` in-place reuse, typed across modules), backed by the standalone deterministic host scheduler **`Processes`** in Pen (Rust) and Deno (TS), discovered and schema-validated via `squid:processes`. *(Session Protocol `service::PROCESS` is explicitly out of scope for this plan; see §5.2.)*

All retired syntax, tests, benchmarks, fixtures, codecs, workloads, and dead scaffolding are migrated/removed cleanly in their owning phase checkpoints (complete Phase 1 and Phase 4 inventories in §6.2).

## 2. Language Design, Grammar, Purity Proof & Wire Schemas

All four grammar implementations (`compiler-goose/src/parse/{lexer,parser}.goose`, `host/parser/grammar.baba`, `host/format.ts`, and `editor/tree-sitter-squid/{grammar.js,queries/highlights.scm}`) are updated in lockstep.

### 2.1 Reserved Keyword `spark`: Data-Parallel Ordered Map

```squid
// Pure expression with infix operators, outer scalar/read-only captures, branchless `if`, and helpers:
func scale_bias (xs: #[F32]) -> (scale: F32) -> (bias: F32): #[F32] =>
  spark #[x * scale + bias | x <- xs]

// Range-affine contiguous streams (vectorizes to 4-wide v128.load + v128.store):
func add_arrays (a: #[F32]) -> (b: #[F32]): #[F32] =>
  spark #[a[i] + b[i] | i <- 0..min a.length b.length]

// Non-numeric pure map (compiles to preallocated direct loop):
func project_points (pts: #[Vec3]) -> (origin: Vec3): #[Vec3] =>
  spark #[Vec3.sub p origin | p <- pts]
```

**Grammar & Lexer Rules:**
```
SparkExpr = "spark" "#[" CollectionExpr "|" Pattern "<-" (Range | Expression) "]"
```
- **`spark` is a reserved keyword** in [spec.md §3.3](../docs/language/spec.md#L100-L105) and `lexer.goose`. **BOTH** existing local loop variables named `spark` across all four repos ([gdev/src/actors/kites.sq:536, 540](../../gdev/src/actors/kites.sq#L536-L541)) are renamed to `spark_index` at both their bindings and their uses.
- **Top-level `|` delimiter:** Uses existing `CollectionExpr` ([grammar.baba:169-175](../host/parser/grammar.baba#L169-L175), `parser.goose:collection_element`), where unparenthesized `|` always begins the generator; bitwise OR inside `body` is parenthesized `(a | b)`.
- **Highlighting:** `spark` highlights as `@keyword.control`.

**Static Semantic Rules (enforced in `check.goose` & `uniqueness.goose`):**
1. **Single unguarded generator:** `pat <- source` where `source` has array type (`#[T]`, `#[+T]`, `#[~T]`, `#[n; T]`, `&[T]`, `*#[T]`) or `U32` range `start..end`. Multi-generators and filter guards are rejected (`spark_generator`).
2. **Irrefutable generator pattern:** `pat` must be irrefutable (`_`, binding name, or irrefutable tuple/record/single-constructor pattern). Refutable patterns like `$Some x <- xs` are rejected (`spark_generator`).
3. **Source evaluation:** `source` evaluates once before the map; its own effects obey normal `use` rules. For range `start..end` with `start >= end`, length is `0` (`if end > start then end - start else 0`, matching [function_control.goose:2143](../compiler-goose/src/direct/function_control.goose#L2143)).
4. **Pure body (`! {}`) & relational read-only proof (§2.5):** `body` is checked with a forced empty effect row (`spark_effectful`), cannot shadow (`:=`), store (`=`), or consume (`own`) outer bindings (`spark_capture`), and **cannot mutate any storage reachable from outer captures, the generator source, or module globals directly OR transitively** (`spark_mutates_capture`, §2.5). Pure-local scratch allocations created inside `body` (including outer fresh array copies created via `@storage.copy`) may be mutated freely.

### 2.2 Multi-Core Parallel Batch Kernels: `entry kernel`

Every module-level kernel writes its full public wire interface upfront ([spec.md §1 Rule 5](../docs/language/spec.md#L33-L36)):

```squid
// Form 1 — Stateless kernel (1-arg):
entry kernel func mix_u32 (x: U32): U32 =>
  (x * 1664525) ^ 1013904223

// Form 2 — Prepared-context kernel (explicit wire interface; internal PreparedCtx stays private):
// Supports fixed-width Out (`#[392; F32]`) OR compact variable-length Out (`#[F32]`):
entry kernel plan_routes : Kernel [#[F32], RouteQuery, #[F32]] = {
  prepare: prepare_route_world,   // #[F32] -> RouteContext ! {}
  run:     plan_one_route,        // RouteContext -> RouteQuery -> #[F32] ! {}
}
```
- **Represented opaque handles in `std/prelude.sq` (runtime-distinguishable & non-forgeable!):**
  ```squid
  // 7-word runtime representation: (kernel_id, binding_hash, ctx_schema_hash, io_schema_hash)
  type Kernel [ctx, item, out] is opaque = (U32, (U32, U32), (U32, U32), (U32, U32))
  // 1-word runtime representation: process_id
  type Process [cfg, cmd, reply] is opaque = U32
  ```
  - Because `is opaque` hides its constructor outside `std/prelude.sq` ([parser.goose:430](../compiler-goose/src/parse/parser.goose#L430)), user code cannot forge `$Kernel` or `$Process` (and both remain automatically banned from `FlatNumeric` wire positions by §2.4's unconditional `is opaque` ban).
  - Each `entry kernel foo : Kernel [Ctx, Item, Out] = { ... }` (and `entry kernel func bar (x: Item): Out => ...`, with `Ctx = Unit`) synthesizes a real entry-module `const` binding `foo : Kernel [Ctx, Item, Out]` initialized with its exact compile-time `(kernel_id, binding_hash, ctx_schema_hash, io_schema_hash)` 7-word tuple! Two kernels of the same `Kernel [Ctx, Item, Out]` type selected dynamically (`if flag then k1 else k2`) carry distinct runtime values!
  - `std/kernel` exposes typed public helpers (`kernel.id`, `kernel.binding_hash`, `kernel.ctx_schema_hash`, `kernel.io_schema_hash`, `kernel.run_batch`, `kernel.upload_context`) that read the represented handle directly via `std`-only `@flat.*` intrinsics — **zero `std`-only intrinsics called from user/Gdev code, zero stringly-typed names, 100% type-checked and runtime-sound!**
- **Grammar & explicit `grammar.baba` productions (`CallablePath`, preserving `private entry func`!):**
  ```
  CallablePath     = (LowerName ".")? (UpperName ".")* LowerName
  EntryKernelDecl  = "entry" "kernel" FuncDecl
                   | "entry" "kernel" LowerName ":" Type "=" "{" "prepare" ":" CallablePath "," "run" ":" CallablePath ","? "}"
  EntryProcessDecl = "entry" "process" LowerName ":" Type "=" "{" "init" ":" CallablePath "," "step" ":" CallablePath ","? "}"
  ```
  - **Named-function-only callables (`CallablePath`):** Aligns with [grammar.baba:40](../host/parser/grammar.baba#L40) (`function_name`), supports plain (`foo`), module-qualified (`routes.prepare`), and type-associated (`Planner.init`, `routes.Planner.step`) functions, and rejects arbitrary expressions. `check.goose` verifies each resolves strictly to a **named function `Body` (`Body.is_function == true`) of the exact required parameter arity** (rejecting named value/pool initializers!).
  - **Visibility preservation ([parser.goose:146](../compiler-goose/src/parse/parser.goose#L146), [tests/host/syntax.test.ts:5](../tests/host/syntax.test.ts#L5)):** Ordinary `private entry func` remains 100% allowed (`entry private` remains rejected per `parser.goose:148`). `private entry kernel` and `private entry process` are rejected cleanly in `parser.goose` / `check.goose`.
  - `kernel` and `process` are contextual modifiers valid only immediately after `entry` in the entry module, highlighted as `@keyword.storage.modifier`.

**Static Semantic Rules:**
1. **Purity (`! {}`), deeply-immutable global reads only, & relational read-only proof (§2.5):**
   - `prepare` and `run` (and stateless `func`) must have empty effect set (`! {}`) (`kernel_effectful`), must NOT mutate any module global, AND **every reachable module global read (`let` OR `const`) must satisfy `deeply_immutable[g] == true` (§2.5)** (accepting computed immutable `const` pools like `array.prefix_sums`/`filter`/`seal`, while rejecting mutable `const` pools like [storage_generic_readers_execution.test.ts:8](../tests/guest/storage_generic_readers_execution.test.ts#L8)!).
   - `run` (and stateless `func`) must NOT mutate any storage reachable from `PreparedCtx` or `Item` (`kernel_mutates_context`). Pure-local scratch buffers (and outer array `@storage.copy` buffers) created inside `run` ARE allowed.
   - `prepare` must NOT mutate any storage reachable from `WireCtx` (`kernel_mutates_context`).
2. **Prepared context (`PreparedCtx`, Form 2):** `prepare : WireCtx -> PreparedCtx ! {}` and `run : PreparedCtx -> Item -> Out ! {}` (non-`own`); `PreparedCtx` must be `PersistentSafe` (§4.2.2); `WireCtx` must be `#[U32]`, `#[F32]`, or `FlatNumeric` (§2.4).
3. **Wire item & result types (`Item`, `Out`) & compile-time stride bounds:** `Item` must be non-zero-width `FlatNumeric` (`in_stride >= 1`, checked `in_stride * 4 + 4 <= transport_budget`); `Out` must be fixed-width `FlatNumeric` (`out_stride >= 1`, checked `out_stride * 4 + 4 <= transport_budget`) OR variable-length numeric array (`#[U32]` or `#[F32]`, `variable_output = true`, `out_stride = 0`).

### 2.3 Typed Isolated Stateful Processes: `entry process`

```squid
// `init` and `step` can live in ANY imported module—no `_step` suffix, no single-file hack:
type PlannerState is data = $PlannerState { seed: U32, history: #[+U32] }
type PlannerCmd   is data = $Step { delta: U32 }
type PlannerReply is data = $Score { value: U32 }

entry process planner : Process [U32, PlannerCmd, PlannerReply] = {
  init: planner_init,   // U32 -> PlannerState ! {}
  step: planner_step,   // own PlannerState -> PlannerCmd -> (PlannerState, PlannerReply) ! {}
}
```
- **Static Rules:**
  1. `init : Config -> State ! {}` and `step : own State -> Cmd -> (State, Reply) ! {}` (both named-function `CallablePath`s of exact arity, pure `! {}`, deeply-immutable global reads only, no writes to `Config`/`Cmd` reachable storage or globals per §2.5; `step` MAY mutate its `own State` parameter!).
  2. `State` must be **`PersistentSafe`** (§4.2.2).
  3. `Config`, `Cmd`, `Reply` must each be `Unit`, `FlatNumeric` (checked `stride * 4 + 4 <= transport_budget`), `#[U32]`, or `#[F32]` (§2.4).

### 2.4 Canonical `FlatNumeric` Wire Layout, Compiler Codecs, Opacity Ban & Complete Schema Identity

Every flat numeric type crossing `entry kernel`, `entry process`, or `@flat.encode`/`@flat.decode` has **one deterministic canonical layout**:
- **Eligible leaf types:** `U32` (tag `1`), `Bool` (tag `2`, canonical `0` or `1` — unpacking traps in wrappers or returns `$Nothing` in `@flat.decode` if `word > 1`), `F32` (tag `3`, IEEE-754 little-endian 32-bit bits).
- **Eligible composites:** Tuples `(A, B, ...)`, closed records `{ ... }` (**UTF-8 lexicographical field-name order**, [direct/types.goose:360-377](../compiler-goose/src/direct/types.goose#L360-L377)), single-constructor non-recursive **`is data`** wrappers (`Vec2`/`Vec3` in [std/vector.sq:2-3](../std/vector.sq#L2-L3)), and literal-sized arrays `#[K; T]` (`K >= 1`, `T` `FlatNumeric`, checked width from [check/storage_types.goose:104-112](../compiler-goose/src/check/storage_types.goose#L104-L112) with overflow-checked multiplication).
- **Unconditional `is opaque` wire ban ([guide.md:1920](../docs/language/guide.md#L1920)):** `is opaque` types are unconditionally rejected recursively before lowering in ALL `FlatNumeric` wire positions (`WireCtx`, `Item`, `Out`, `Config`, `Cmd`, `Reply`, `@flat.encode`, `@flat.decode`), even inside their defining module.
- **Wire transport type & honest JS scalar `F32` NaN contract ([host/guest.ts:732](../host/guest.ts#L732)):**
  - All-`F32` leaves → `Array F32` (`elem_tag = 3`), except variable-length kernel output which ALWAYS uses `Array U32` (`[len_0, word_0..., len_1, word_1...]`, bitcasting `F32` via `i32.reinterpret_f32`/`f32.reinterpret_i32`). Otherwise → `Array U32` (`elem_tag = 1`).
  - For 1-word `FlatNumeric` `Config`/`Cmd`/`Reply` in `entry process` (`stride == 1`), direct scalar ABI tag (`U32`/`Bool`/`F32`) is used on the wire AND the wrapper still runs the recursive `FlatNumeric` codec (materializing 1-word owner wrappers like `#[1; U32]`).
  - **Scalar `F32` JS host-boundary NaN contract (documented in `docs/host/guest-abi.md`):** Array packets copy raw 32-bit IEEE-754 bits verbatim across Rust and JS/V8. Per the WebAssembly JS API (`ToWebAssemblyValue`), JS↔Wasm scalar `f32` conversion preserves all finite values, signed zeros, and infinities, while arbitrary implementation-defined NaN bit patterns are NOT preserved across the JS scalar `f32` boundary (use `U32` bit-words or array packets for portable bit-exact NaN transport across JS).
- **Compiler-Synthesized `std`-Only Codecs & Variable-Row Framing:**
  - `std`-only intrinsics (rejected outside `std/`): `@flat.encode : a -> #[U32]`, `@flat.decode : #[U32] -> Maybe a` (validates `src.length == stride(a)` BEFORE allocating; fresh materialized ownership, NEVER aliasing `src`!), `@flat.schema_hash [T] : () -> (U32, U32)`, `@flat.kernel_id : Kernel [c, i, o] -> U32`, `@flat.kernel_binding_hash : Kernel [c, i, o] -> (U32, U32)`, `@flat.kernel_ctx_hash : Kernel [c, i, o] -> (U32, U32)`, `@flat.kernel_io_hash : Kernel [c, i, o] -> (U32, U32)` (reading the represented `Kernel` tuple fields directly at runtime!).
  - **`std/kernel` service framing:** Fixed-width `encode_fixed_f32`/`decode_fixed_f32` (16-bit lossless split `[lo, hi]` in `0.0..65535.0`, or finite-validated 1:1 `#[F32]` pass-through for all-`F32`); variable `#[U32]` 16-bit split `encode_var_u32_f32`/`decode_var_u32_f32`; variable `#[F32]` `[row_len as F32 (exact integer in 0..16384), elem_0...]` finite-validated `encode_var_f32_f32`/`decode_var_f32_f32`.
- **Complete Canonical Schema Bytes, Closed Core Type/Effect/Provider Encoding & ONE Unified `binding_hash`:**
  - **Algorithm & collision policy:** FNV-1a 64-bit (`offset = 0xcbf29ce484222325`, `prime = 0x100000001b3`) is a **64-bit non-cryptographic fingerprint** paired with exact structural `WireSchema` fields (`kind`, `wire_tag`, `stride`, `word_tags[stride]`) — standard ~2⁻⁶⁴ collision bound, not claimed collision-free.

### 2.5 Context-Sensitive Relational Storage-Graph Purity Proof (`checkReadOnlyFootprint`)
Because Squid allows writes through ordinary array aliases ([guide.md:635](../docs/language/guide.md#L635)), mutable `const` pools ([storage_generic_readers_execution.test.ts:8](../tests/guest/storage_generic_readers_execution.test.ts#L8)), `@array.generate` implicit generator calls (`std/array.sq:17`, `function_storage.goose:923`), `@storage.pop` returning nested owners (`function_storage.goose:1153`), `@simd.load`/`@simd.store` admitting array-valued lanes ([collection_ops.goose:26-27](../compiler-goose/src/backend/collection_ops.goose#L26-L27), [check.goose:3462-3469](../compiler-goose/src/check/check.goose#L3462-L3469), [function_storage.goose:725-734](../compiler-goose/src/direct/function_storage.goose#L725-L734)), `@storage.share` (`1189`), `with` cells (`function.goose:602`), and handled `state_set` (`function_entry.goose:343`), `check.goose` / `uniqueness.goose` computes **context-sensitive per-function relational summaries** over finite symbolic storage graphs:

- **Finite symbolic node domain & separated labelled containment per body `fn`:**
  - **Finite edge label domain `EdgeLabel`:** `Elem` (array/collection element), `RecordField(name)` (closed record field), `TupleSlot(i)` (tuple position), `CtorPayload` (data/opaque constructor payload), `CaptureSlot(i)` (closure captured binding/cell slot), and `Any` (wildcard containment for pre-existing symbolic children and opaque cells).
  - **Pre-existing outer roots & immutable `contains_base` vs. concrete `contains_written`:** Pre-existing outer roots `R ∈ {Param(j), Capture(c), Global(g)}` each have an explicit derived child node `Child(R)`.
