# Source/target-bound scalar leaf resource preflight (scratch)

The producer accepts the existing source-owned typed U32→U32 scalar/finite-loop arena, not an arbitrary callable graph. The independent consumer rechecks exact original source, the typed arena, every supported operation/binding class and the complete independently decoded emitted Wasm target. This subset contains only U32/Bool scalar locals, fixed built-in scalar operations and finite range loops. Its checked baseline has no user calls, aggregates, captured environments, K1 linear-memory loads/stores or other K1 frame allocations. The body therefore needs one callable depth and zero K1-managed linear frame bytes. Wasm locals and host/engine stack are separate and are **not bounded by this statement**. The independent target checker must be trusted to enforce its documented no-call/no-memory-op subset.

The retained source summary records both the inferred body requirement (1/0) and the exact declared contract. Preflight rechecks source, typed tree, target and every summary field before considering budgets; it uses the declared, possibly wider depth and frame contract rather than silently narrowing at the call site. `depth_used` is the count of already-active callers and `frame_used` the existing K1 frame frontier. Given trusted invocation-local `depth_limit` and `frame_limit`, it rejects a target if the declared contract does not fit the remaining depth (bounded by 128) or frame capacity, using subtraction checks to avoid U32 overflow. On success it returns a fresh copy of validated Wasm; on source, depth or frame failure it returns no bytes. This is a source-bound admission/planning check, not an automatically invoked runtime wrapper, reserve/restore implementation, deployable manifest or public authority. Its scalar capacity numbers are comparison inputs, not authenticated runtime state.

O0/O2 tests include identity and loop sources, wider advertised depth/frame, U32-max frame and used-frontier boundaries, source/Core/summary forgeries, all target-byte flips/truncations and returned-byte ownership. Actual emitted targets execute expected results for edge inputs. User function calls, nested closures, aggregates, effects, dynamic loans, arbitrary return types and unsupported syntax are rejected by the existing source checker. No call-graph composition, source-level general frame accounting, qualified host ABI, engine provisioning, C09, M11 or public K1 eligibility is claimed. File emission by the test is deliberately outside `admit`; a production pipeline must wire invocation-local limits and publication atomically and execute the check before source effects.
