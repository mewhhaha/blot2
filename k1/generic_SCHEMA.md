# Private source-bound generic identity fixture

This experiment accepts one one-line public declaration of an unconstrained
rank-one Type identity. It supports different function, type-binder and
parameter names, but requires the fixed callable, empty effect set, depth 1,
frame 256 and explicit `return` of its parameter. The verifier independently
re-lexes that source and checks the completed body's spans, one move, zero
copies and zero discards. Parser output alone does not grant authority.
Multiline headers, generic applications, other generic bodies, type inference,
proofs, callbacks, work accounting and public K1 admission are not implemented.

The dictionary component accepts only Unit, a one-word scalar, a flat product
of up to 64 U32 words, and a two-word affine descriptor. Its four U32 fields
are size, alignment, flags and owner-local schema ID. A separate decoder checks
exact canonical component bytes, all field values and an independently supplied
schema identity/ID. Caller-supplied canonical bytes and producer IDs must come
from a trusted checked type/schema owner; this component neither derives them
from source nor makes a numeric ID or flag word an authority. It does not
validate refinements such as a Bool's 0/1 representation.

The limited layout calculation checks the 64-byte Plain element limit and the
256-byte aggregate Result boundary, including the four-byte tag. Slot geometry
checks bounds, alignment and non-overlap of input, output and dictionary, and
requires initialization/exclusivity evidence from its caller. The checked entry
reconstructs its plan from source and the expected dictionary rather than
trusting a caller-supplied plan. Booleans passed
to that helper are placeholders for trusted compiler evidence, not host or
source-provided authority. Full layout/ownership/loan obligations are absent.

For checked inputs the fixture emits one fixed Wasm worker with parameter order
`(environment, result slot, dictionary, argument slot)`. It loads the dictionary
size and moves exactly that many bytes with `memory.copy`. The worker has one
fixed page, no imports and no `memory.grow`; memory is exported for the test.
An independent exact-format checker revalidates the source and output bytes.
Its linked entry additionally recomputes the request's source/body/dictionary
association against the independently expected schema before checking output.
The Node witness uses the actual independently checked four-word dictionary
records generated by Goose and exercises the same worker at 0, 4, 8, 64, 252
and 256 bytes. Zero size uses address zero and transfers no bytes. Logical move
consumption, initialized inputs, immutable dictionaries and exclusive result
slots are compiler preconditions, not dynamically established by this raw
fixture export.

The source key and emitted bytes are identical across the tested substitutions,
but this model regenerates the module on each request. It does not establish a
once-only compilation count, a retained generic-body cache, nominal type
substitution across imports, an ABI hash, a portable checked artifact, or an
executable provenance certificate. Hashes are not authorization to reuse.
