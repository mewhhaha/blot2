# Private fixed particle-worker address and initialization witness

This scratch fixture requires the separately source-bound exact target pin and the existing private helper instruction-shape checker. It independently checks CFG dominance for sixteen unconditional project error guards and for the worker loop bound, and matches all 78 worker instructions against an independently transcribed sequence. The sequence establishes that each loop index below the input count reads four F32 fields at `input + 16*i + {0,4,8,12}`, writes two F32 fields at `output + 8*i + {0,4}`, then stores initialized prefix `i+1` before incrementing the index. The zero-count and completion descriptor stores are also matched. Project helper structure and error dominance do not by themselves authenticate storage or source ownership.

`geometry` is a separate pure arithmetic witness for count and capacity 0..8 and four-byte-aligned placements in a single 192-byte owner region, assuming nonoverlapping input and output ranges. It computes each iteration's read/write ranges and prefix progression and exposes no authority to run a target. Its offsets are model values, not authenticated Wasm descriptors; input initialization, owner state, provenance, loans, and exclusivity are external preconditions. In particular a successful geometry result alone cannot admit a call.

The test exhaustively compares this arithmetic model with an independent interval predicate over all 194,481 bounded aligned geometries and exercises 44,193 valid geometries, thirteen valid-Wasm unsafe mutations without relying on the pin, and all 5,769 byte XOR mutations and truncations through the pinned entry. This is not a general Wasm analysis, a proof of all helper effects or initialized input, a complete execution semantics or M11 qualification. It assumes trusted JS/Wasm intrinsics and single-threaded target snapshots. The deliberately unpinned diagnostic is for negative tests only and returns no eligibility.

Run `node /path/to/k1/i08_worker_flow_test.mjs` in the test directory on the target already produced and source-verified by the guarded caller-flow test.
