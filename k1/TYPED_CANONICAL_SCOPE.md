# Private scalar/finite-loop typed arena experiment

This source-bound candidate builds one mixed scalar/finite-loop tree for one U32 -> U32 public-shaped declaration. It permits inferred U32 and Bool lexical lets (no type annotations), validates each binding's lexical scope and derived type, and rederives the node and binding type arrays during checking. An independent source recognizer, independently retyped proof consumer and independently decoded target are required before emission. Bool values are ordinary typed i32 values; tested comparisons/literals are canonical.

A Boolean local is deliberately opaque as a later condition: `let safe = x < MAX; if safe: return x + 1` is rejected because no checked predicate provenance is transported through `safe`. Loop body checking starts with fresh aliases/facts; no unproved backedge fact is carried. The supported arithmetic/proof/loop grammar is the existing bounded mixed subset. This is not general SSA, loop invariants, Bool arguments/results, annotations, ownership/loans, effects, declared-resource checking, general error diagnostics, ABI, M13, C09 or public admission. Full old-path status, byte and source-limit parity and performance are not established; old dispatch is untouched. The expected original source must be independently retained and immutable, with no concurrent mutation during checking.
