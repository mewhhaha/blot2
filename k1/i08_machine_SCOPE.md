# Private fixed-target Wasm graph and partial slot skeleton

This scratch experiment independently decodes the bounded direct-call instruction subset of one source-checked, fixed Wasm module. It requires an exact embedded byte match to the fixture, validates the Wasm module, rejects imports/unsupported sections/indirect calls/resource growth, parses bounded/canonical integer immediates and local/memory operands, and extracts direct call edges. From function 22 it derives a maximum of six nested Wasm functions; it detects cycles rather than assuming a depth. The existing source/target gate must independently check and emit the exact target at Goose O0/O2 before running the decoder.

The separate fixed-target slot-skeleton checker enumerates frame-range constants in functions 18/20/21/22, verifies the zero-frame marker sequence, the checked shim's fixed slot comparisons, fixed call argument addresses, and selected direct constant-address record/scratch stores and result loads. It checks those extracted offsets against the fixture's `[49152,49176)`, `[49184,49192)`, `[49280,49300)` and `[49312,49328)` intervals. Tests alter every target byte and truncate at every offset, and additionally create valid Wasm with a modified call edge, frame address or F32 opcode; all are rejected by exact target association. Hostile typed-array inputs and cyclic graph controls are included.

This is not a complete frame-access or M11 proof. Loads and stores through dynamic locals, all branch-dominance/descriptor facts, the bounds of separately called helper bodies, call classification, source-to-runtime loans and actual affine cleanup are not established by this slot skeleton. Six is a **raw Wasm function-path count**, not a K1 callable-depth certificate; helper functions and the canonical/flattened adapter require an independently checked classification and frame contribution. The 768-byte reservation remains unqualified, and neither machine nor engine/native stack bounds follow from this test. Results explicitly report `dynamicAccessesQualified=false` and `m11Qualified=false`.

The exact byte pin is a private fixture anchor, not a portable hash or arbitrary-artifact authentication. The generated module and this checker are not a general compiler admission path. The decoder snapshots input and treats JavaScript/WebAssembly intrinsics as trusted. This is not a complete Wasm validator or C09/M13 certificate.
