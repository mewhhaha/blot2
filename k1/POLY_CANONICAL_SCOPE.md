# Private typed scalar/loop callable experiment

One source-owned mixed arena represents a public-shaped noncapturing callable with U32 or Bool input and U32 or Bool result, an explicit empty effect row, inferred U32/Bool lexical lets, and the existing bounded scalar/finite-loop control subset. Arrow and `Fn[static,Many,A,B]` signatures are accepted. The full original header is rederived from immutable expected source; the projected body is independently recognized, with node and binding types separately reconstructed before proof and target checking. The emitter is gated by a closed independent target decoder.

Bool input is a raw i32; the fixture caller must provide canonical 0 or 1. Bool results are canonical under that precondition. Bool variables never authorize numeric operations, bounds, carries or facts, and a Bool local does not transport its initializer's predicate as an arithmetic proof. Each loop body starts with fresh fact/alias state. Source syntax and proof rules remain the existing bounded mixed subset: no Bool short-circuit operators, type annotations, calls, full finite facts, general loops/invariants or ownership/loan authority. Declared resources are parsed but not proved. No public ABI, M13, C09, artifact provenance or full compiler admission follows.

The source request must be independently retained and immutable during checking and emission. The 48-case U32 old/new status/target-byte comparison is sampled, not full equivalence. Existing dispatcher remains unchanged and no compilation/runtime speed claim is established. An independent bounded-subset audit passed at O0 and O2; it does not establish general compiler completeness.
