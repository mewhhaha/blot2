# Private source-owned scalar arena compatibility investigation

The scratch `short_parse` and independent `short_verify` accept a single `return` after `fn x =>`, replaying its original source tokens and lexical binding directly into the existing mixed arena. Other one-line statements, multi-statement bodies, mismatched types, unsafe checked arithmetic, and nonempty effect rows remain rejected.

`short_legacy_wasm::emit` accepts only the original-source-verified arena for a single U32 less-than U32 return and derives the prior scalar plan from its bound nodes; its existing independent scalar Wasm validator rechecks that plan's source association and target bytes. A failed compatibility lowering is not acceptance and can be followed by the already-checked mixed backend. This compatibility encoding does not qualify a public ABI, source effect or resource declarations, ownership, C09, or M13; source is expected immutable during checking. The parser, independent replay and compatibility lowering were independently audited. The separate `primary_dispatch::compile` is an opt-in private source-owned arena-first entry; it retains the old dispatcher on parse failure and is not wired to a public CLI.

The O0/O2 literal-source corpus probe extracts 435 distinct public-shaped sources from repository tests, compares the old dispatcher to the scratch arena and compatibility target, and observes 70 both accepted with identical output and argument/result, zero old-only, 28 newly accepted, and 46 differing rejection statuses. This is a finite sample and does not establish full syntax, status or byte parity. Differing old->new rejection counts: 1->5:1, 2->1:9, 7->1:3, 14->1:3, 13->3:2, 1->3:3, 11->1:6, 5->1:8, 4->1:7, 2->3:1, 4->3:2, 15->1:1. Simply replacing the dispatcher would change diagnostics; retaining an old diagnostic fallback reduces migration benefit and cannot establish complete parity without further cases.

The dedicated O0/O2 test checks 64 operand/header/body forms against the old target bytes, source and arena forgeries, unsafe arithmetic/effects/extra-statement rejection, and executes the generated Wasm at U32 boundary values. Existing short, ops, predecessor-proof and deep-chain O0/O2 focused groups also passed against this scratch copy. Independent source-byte and tree/binding/type forgery controls passed O0/O2.

For the private arena-first entry, the compatibility builder distinguishes a source-validated legacy match from an unsupported pattern. Once matched, emitter or target-validation failure fails closed with no output; O0/O2 tests inject both failures. Pre-match scalar-validator rejection still selects the checked modern target, and the unmetered pre-match validation has no modeled allocator/OOM or C09 failures, so exact byte parity under those failures is not established. The 435-source and independent 104-case matrices give sampled, not complete, old-target/status parity.
