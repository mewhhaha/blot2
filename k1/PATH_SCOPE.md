# Private short-circuit predecessor proofs

The source-bound mixed scalar/loop checker evaluates `&&` RHS under the independently reconstructed true predecessor of its left operand and `||` RHS under the false predecessor. Literal-dead operands are omitted from arithmetic proof traversal only after the independent source and type checker has checked the entire tree. Common output facts require identical source guard ID and polarity on every live predecessor. Nested paths retain exact alias/guard provenance, while each loop body starts with fresh aliases/facts and no unproved backedge transport. The independent evidence consumer replays this reasoning, rather than trusting the producer's evidence.

The bounded rules include strict `<`, exact `x <= 4294967294` true edge, and the false edges of `4294967294 < x` and `4294967295 <= x`. It is not full finite-fact or reachability closure: joins may discard logically equivalent facts with different origins, Bool-local values do not transfer their initializer's predicate, and the existing completion checker can conservatively reject valid literal-composite control paths. There is no general loop SSA or invariant transport, ownership/loan, qualified resource, public ABI, M13, complete C09, or performance claim. Bool input requires caller-supplied 0/1; expected source is independently retained and immutable during checking.

O0/O2 scratch tests cover exact true/false short-circuit guards, pruned-but-typechecked operands, source/alias/evidence forgeries, unsafe OR joins and loop-fact leakage, U32 boundary execution, and sampled old target-byte compatibility. This candidate changes two fact modules only; existing tests that asserted safe short-circuit expressions reject must be deliberately updated if adopted. Independent O0/O2 review covered the predecessor replay and bounded heap-backed traversal, including chains at the former recursion failure threshold and forged cycles. The explicit stack is limited to 128 frames and traversal to 32768 steps; allocation failure is not handled as a host out-of-memory guarantee.
