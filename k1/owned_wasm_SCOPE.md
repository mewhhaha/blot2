# Private source-checked Owned Wasm execution experiment

This bounded experiment compiles the exact closed module accepted by `owned_chain`: one source-derived scalar consumer, fixed transparent U32 aliases, a single literal-sized scalar Owned construction, exhaustive Result handling and a direct call. The target has private one-page Wasm memory, one source-structured consumer and only an `invoke() -> i64` export. It encodes the private fixture result in a status/value word, not the K1 aggregate Result ABI. No externally supplied owner, handle, memory, clock or loan enters the instance.

The consumer's checked source tree determines actual machine control, including `if` branches and nested lexical openings. The generated private state machine checks a live sealed capsule, tracks each open/end and move, forbids close while loans remain and clears the active owner on close. It stores/loads the actual scalar in memory. The wrapper models one fixed reservation, distinguishes reserve failure from Body abort, calls the exact consumer, and checks state/loans cleared before success. On valid input this reproduces the existing private native fixture's status/value, including correct overflow and capacity thresholds. A separate structured decoder rechecks source, tree and entire target sections/opcodes against those transitions and disallows imports, unknown effects, unexpected calls and extra exports; `owned_wasm_compile` returns no bytes if decoder verification fails.

This is not the K1 allocator/control-record/bitmap representation, canonical aggregate slots, Result or Owned ABI, generalized region identity, external capabilities, public artifact certification, M11, C09, or a general compiler implementation. The decoder and emitter share the source plan extractor and low-level Wasm helpers, though independent existing source recognizers and a native oracle also check the source; the binary does not carry a unique source hash. Source-mutable-during-check, host/engine compromise, traps, OOM and process exhaustion are not qualified. Trap recovery/poisoning is not implemented. The fixed private state has no external concurrency or memory export; success/failure observations are limited to the fixture interface. Real independently trusted Wasm runtime and its memory initialization are assumed.
