# Private prior-dispatch disposition

The old private source dispatch now records whether its own frontend recognized the source during the original compilation. The outer `typed_dispatch::compile_record` initializes its caller-owned output flag; internal chain helpers propagate that same local flag and must not use a forged or shared flag. The `primary_dispatch` creates a fresh local and consumes the flag only to decide whether a failed previous compilation must stop. It never accepts a flag as source or target authority. Existing independent source and target validation remain in place. Source is immutable across the call.

Each old frontend marks recognition before target emission. A recognized emission failure propagates immediately through common and typed dispatch instead of trying the next compiler; independently forced empty emitters and fault modes 10–15 cover all six source frontends. Ordinary old successful output and previous diagnostics were compared with mechanically namespaced frozen baseline on 435 source cases at O0/O2; a 104-case independent matrix also passed. The call-local disposition was compared with independent six-frontend replay across every byte mutation and strict truncation of seven cases. This is sampled evidence, not complete compatibility proof.

The removed replay was not covered by a complete semantic work meter; no C09 accounting-equivalence claim is made. Runtime allocation failure or host OOM cannot be returned reliably by Goose and is not qualified. Public ABI, complete resource/effect/ownership checks and public language admission remain unqualified. A controlled comparison against the six-parser replay is recorded in `measurements/2026-10-27-disposition/RESULTS.md`; it is limited to the private paths and does not establish complete C09 or full compiler performance.

Reviewed production files are `k1/generic_callable.goose`, `k1/common_decl_dispatch.goose`, `k1/typed_dispatch.goose`, `k1/primary_dispatch.goose`. New tests `k1/primary_disposition_test.goose`, `k1/primary_disposition_six_fault_test.goose` need only `"$GOOSE" --quiet --debug "-O$level" "$script_dir/<name>.goose"` in the existing O0/O2 loop. The frozen-baseline test depends on three mechanically copied prior modules and can remain a dedicated independent audit unless durable baseline snapshots are desired.
