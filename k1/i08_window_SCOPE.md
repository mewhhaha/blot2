# Private fixed-window particle wrapper

This source-linked scratch fixture adapts one fixed particle source and one fixed checked Wasm target to an eight-word ingress/egress header. Its input payload is F32 time followed by one `{count,byte_offset}` descriptor and particle records `{x:F32,y:F32,vx:F32,vy:F32}`. It snapshots input, validates tag/export/header/count/alignment/range/zero padding and numeric output capacity before the worker, then invokes the reviewed private one-region bridge exactly once. It publishes a fresh output frame only on success; insufficient capacity is reported after that one invocation with no payload. Invalid input, modeled frame failure and injected reservation failure publish no payload. A trapped or internally damaged fresh instance is discarded and the wrapper is poisoned; returned data and headers are host-owned copies.

The suite reuses the `i08_live_source_test.goose` source/header/type/bounds/affine/target gate at O0 and O2. The wrapper tests compare its generated target to the pinned fixture and run boundary/fault checks plus a 10,000-input independent wire oracle. The pinned bytes and export 91 are a fixed private fixture, not caller-supplied manifest authority.

**This is not a qualified M12 implementation.** The recognized source has a tuple-shaped View/F32/Builder input and an existential View return, not the required source-checked record/Dest/Result adapter. Only this one schema, fixed F32 particle layout and no source-returned input alias are supported. The 768-byte frame reservation is a local JavaScript accounting model; the generated target has no qualified K1 frame arena or independently proved wrapper frame bound. The worker setup's actual descriptor checks and its cleanup are exercised through the trusted private bridge, but error disposal is not a proof of source-level affine cleanup. Reservation failure and pre/post-call traps in the tests are injected controls, not source language failures. No public ABI/manifest hashes, formal capability provenance, full C09, general effects, arbitrary schemas, concurrent SharedArrayBuffer mutation, hostile intrinsic tampering or full F32 NaN-result-set qualification is claimed.
