# Private ABI inventory and source-bound candidate envelope

This experiment replaces the private M12 candidate's opaque caller-selected ABI value with a deterministic digest of a compiler-owned, versioned **inventory candidate**. Its identity is deliberately `PRIVATE-K1-ABI-CANDIDATE1`, not a qualified `K1-WASM32-ABI1` hash. The candidate profile records fixed scalar and aggregate representation, descriptors, owner fields and state encodings, pool/builder rules, dictionary fields and flags, machine parameter/result convention, existential Nat prefixes, selected layout/resource limits, host wire/status/lifecycle rules, and the named primitive families. The canonical bytes are `K1ABI001`, a little-endian U32 count, then 15 ordered U32-length-prefixed key/value records with no padding. The compiler computes BLAKE3-256 over those exact bytes. The separate bounded decoder checks every fixed key and value and recomputes that digest; a digest alone is never used as identity authority.

`K1AMNF01` is a private envelope containing, in order, total length and length-prefixed exact profile, its 32-byte digest, and the existing source-order `K1FMAN01` candidate. Candidate verification checks that the ABI field equals the internally derived profile digest, that the expected trusted source/package/module/adapter match, and that the raw kernel target verifies against that source. The adapter is source-only; the target is not its compiled implementation. Public eligibility and adapter-target/frame/ABI/loan qualification remain false. The `matching_fields` helper compares four already-extracted hash byte strings, but does not parse or authenticate an interface, implementation artifact, manifest or certificate.

This inventory is not a complete M10 representation: it lists primitive families rather than their complete versioned per-overload operand/result/effect/ownership/evidence/failure/target schemas; not every representation/refinement rule, numerical limit, dictionary condition, adapter rule or host-wire constraint is encoded. The specification does not provide a finalized canonical serialized registry for these individual schemas. A qualified ABI identity must cover the complete agreed canonical registry and layouts and must be consistently checked in real independently validated interfaces, implementations, manifests and certificates. This prototype must not be used as that identity or to admit artifacts. Its catalog and separately implemented decoder are manually transcribed from the specification, and require independent semantic review before expanding coverage.

Both envelope readers reject malformed lengths and trailing bytes before following spans. Focused O0/O2 tests mutate every profile/envelope byte, truncate at every offset, mismatch identity fields and source, and recompute a digest over each corrupted profile to prove a digest cannot make a different profile acceptable. The frozen private-profile digest is `d6b574eb25e6d79f920f0ee855b86d0bcc8aae11d384c6ee82a04e1e323bdb9e`; this is a change-detection value for this experimental inventory, not a public ABI hash. No full M12 schema, M13 certificate, live capability, output alias or frame qualification is claimed.
