# Private source-only M12 adapter experiment

The canonical I08 `project` function is not itself an M12 export: it accepts a tuple containing a Builder and directly returns an existential View. This experiment recognizes one closed, separately written adapter source declaration in the same two-declaration module as `project`. The adapter has a single source-ordered record argument containing an immutable particle View, an F32 scalar, and an exclusive `Dest`; it declares a `Result` containing a Nat/Domain existential result View and a Unit error. It consumes the record's destination with `builder.begin_append`, calls the exact checked `project` with both region parameters instantiated to the one invocation region, opens the result's fresh Domain, repackages the exact n and that Domain, and returns `#Ok` once. Its header contains only read/write effects for the invocation region and the kernel's `Le(n,c)` precondition. The closed syntax rejects additional effectful operations, destination reuse, altered substitutions, changed return origin and extra exit paths.

The source producer composes the existing I08 source link, affine plan and conditional induction proof. The separate consumer revalidates those against the retained exact kernel bytes, re-lexes the complete canonical adapter token stream and reconstructs its operation-site trace against the retained full-module bytes. The adapter grammar is intentionally fixed, not a general K1 record, Dest, Result, effect or type checker. The trace's roles are source provenance, not runtime capabilities. Successful checking is conditional on the registered begin/append/freeze contracts, simultaneous valid input loan and exclusive destination, nonoverlap, and a live region; it does not establish those premises from source IDs or host data.

The M12 public eligibility function deliberately returns false. This work does not generate the canonical record/result-slot/`Result` adapter, initialize a real invocation destination, establish the actual disjoint loans or fresh runtime package, validate ABI/layout/manifest fingerprints and windows, preflight the declared frame/depth contract, prove target-source equivalence for this adapter, or implement C09. Existing raw particle Wasm and its private JS wrapper do not implement this source adapter or establish the mandatory M12 ABI. A future checked lowering and bridge must satisfy these independent obligations before any eligibility claim or external execution.
