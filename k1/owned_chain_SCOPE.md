# Private source-derived Owned construction and consumption chain

The complete source must be the closed private module shape checked in `owned_chain.goose`: a source-owned `consume` function for `(Owned[Scalar[_]], Bool) -> U32`, the transparent declarations `Scalar[r: Region] = U32` and `ScalarPayload[r: Region] = U32`, and a `main` which constructs `owned@[ScalarPayload[_],#Cancelled]`, matches both Result cases and passes the sole resulting owner to `consume`. The existing independent ownership checker validates the full consumer source, lexical openings/moves/close on all paths and the explicit release upper bound. The independently verified constructor checks its source and returns either a sealed scalar, Body error or reserve error. The scanner binds the exact names and call site, and deterministically removes only the enclosing two-space indentation before independently parsing the constructor slice.

`run` creates a fresh private native State and Clock, constructs the owner and immediately transfers its handle to the checked consumer; no external handle, State, Clock, loan or caller-provided authority enters the chain. The consumer runner independently rechecks the exact retained prefix before execution. A successful value is returned only after the private owner has been closed and all modeled openings end. Body and reserve failures return distinct private status values. Existing runtime checked-counter preflight remains conservative; fresh state starts safely below its thresholds. Test controls cover success, both boolean arguments, body abort, reservation failure, invalid aliases, use-after-move and source/call/error-path mutations.

This is a native private interpreter witness, not a canonical K1 Result encoding, emitted Wasm, ABI, public artifact, resource or C09 implementation. It supports only the exact source grammar and source-owned U32 consumer, so it does not establish general calls, arbitrary construction, dynamically passed handles, untrusted runtime provenance or concurrent execution. The checked source and private state must remain immutable/nonconcurrently accessed during each call; trusted Goose/runtime/intrinsics and existing fixed one-region pool implementation remain assumptions. Process OOM or runtime traps are not proven transactional. The work does not prove executable target provenance or complete M05/M09.
