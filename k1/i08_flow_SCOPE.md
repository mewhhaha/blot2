# Private guarded-target flow fixture

This bounded check takes one nonconcurrently supplied, source-gate-pinned Wasm image. It constructs structured control-flow successors for the invocation function and checks that its zero-frontier guard, successful `frame_enter`, and the entry result check dominate each checked reservation, descriptor setup and source-adapter call, with error edges unable to reach those calls. It separately interprets reachable adapter and shim instructions using the wrapper's checked literal argument addresses and rejects unknown or out-of-range memory addresses. The permitted metadata loads and fixed frame slots are specific to this fixture. It rejects unknown adapter instructions.

This does not establish allocator/worker/helper effects, dynamic accesses in other functions, actual K1 callable depth, complete language-frame sufficiency, engine stack bounds, general ABI, loan authority, or M11 qualification. The in-memory target pin must itself be established by the independent source/target gate. Host intrinsics, module validation and single-threaded input copying are trusted. `unsafeDiagnosticForTests` tests analysis against unpinned variants; it returns no authority and must never be treated as an admission API.

Run `node /path/to/k1/i08_flow_test.mjs` in a working directory containing the source-gate-produced `private-invoke.wasm`. The test covers the reviewed exact target, eight structurally valid unsafe mutations without the pin, and every byte XOR mutation and truncation through the pinned API. This fixture is not an independent source compiler or a general Wasm verifier.
