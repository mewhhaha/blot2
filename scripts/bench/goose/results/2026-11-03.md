# Blot / Goose direct Wasm, 2026-11-03

Three shared translated kernels now compare cold compilation, Wasm size and
checked runtime in Node 24.22.1 / V8 13.6.233.17-node.58. This covers three of
Goose's seven adapted LangArena tasks, from its 50-task catalog. It is not a
Gdev or whole-language performance result. Exact samples, checksums, hashes and
input configurations are in [the evidence](2026-11-03.json).

The unchanged official production pilot hit the **30-second whole-process limit
on all three Blot cases**. Goose completed them and matched the official
checksums. Those single pilot runs provide no production runtime ranking;
timeout includes preparation, warmup and execution. Bounded results are not
official LangArena production scores. Small-input tests also pass, but their
sub-10ms kernel regions receive no performance ranking.

Blot hash buffers use U32 values with four times Goose U8's element payload
bytes; owner metadata, headers and reserved arenas are separate. Fannkuch uses
nonnegative U32 indices and wrapping accumulation in place of wider Goose
plumbing. All eight hash lanes and the complete digest remain in both programs.
This custom hash is not cryptographic SHA-256. Each measured region includes two
clock crossings through its language's ABI; there are no host calls per element.
Process wall includes the common TypeScript wrapper, so it is not a standalone
Goose startup score. Wasmtime has not been measured.

Kernel artifacts were first built with Blot compiler profiling enabled. The
separate ordinary-build run produces identical hashes for all twelve
case/backend/revision variants, retaining those runtime results without another
runtime run. Both installed compilers are frozen by binary hash, independently
of dirty checkout state:

- Blot: `f5433089972067d2e26dafad2a3c489608af7b2b0ae536d508ac3487fbe8c643`
- Goose: `353a3f1bd547330c8ecd32e9084ae92d616340f81f83a5cc30f2e657d577652e`

This is a shared host; unrelated Rust release compilation was observed. The
custom-hash Blot samples include a 7,593ms outlier. Retain the sample dispersion
and avoid interpreting close compile-time differences as stable rankings. Sieve,
Quick/Merge sorting and Mandelbrot remain unported.

Both the profiled and ordinary batches pass all 60 fresh builds and all 12
small-input revision qualifications. The runtime batch passes 60 measured
samples and 12 process warmups. Independent Python oracles match the official
small and production checksums. Negative controls reject an incorrect checksum
and revision for each backend, and a sleeping child is killed at its configured
50ms cap. An initial bounded pilot had an incorrect warmup configuration key;
checksum validation rejected it, and none of its failed rows are scored.

The next useful hill is inspecting emitted loop and array-access code on these
small cases. Their large runtime gaps provide a focused target while the
existing Gdev size and compilation targets remain separate.
