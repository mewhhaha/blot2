# Private typed callable source entry

`generic_callable::compile(source)` accepts one public-shaped function with a monomorphic, noncapturing U32 -> U32 or Bool -> U32 argument/result signature, written with arrow syntax or `Fn[static,Many,A,U32]`, and an explicit empty effect row. It dispatches the original source to existing source-bound U32 scalar/loop or Bool typed-flow Core verification, then emits the corresponding private Wasm. Bool entry arguments are raw i32 and the caller must supply 0 or 1; this is not a validated host ABI.

The Bool path rechecks exact source, declared signature, header spans, projection and the typed body before emission. Its closed target checker independently decodes the fixed emitted Wasm against that source-bound typed tree before returning bytes; it is not a general Wasm or M13 validator. Its producer and verifier share one header reconstructor. Source/header status 1 denotes malformed or unsupported syntax, while typed Bool body status 13 is an unbound name, 14 is a type mismatch and 15 is a missing return. U32 errors preserve their existing private fixture status; no general diagnostic taxonomy is claimed. All failures return an empty byte array.

General functions, multiple declarations, function calls, parameters/results beyond these two argument types and U32 result, effect rows other than empty, ownership, generics, predicates, closures, multiline headers and one-line bodies are unsupported. Resource declarations are parsed but not proven against actual resource use. The two body families remain distinct checked Core representations with a dispatching entry; they are not a common expression/loop IR. No public compiler admission, authenticated artifact, ABI, M13, or C09 qualification is implied.
