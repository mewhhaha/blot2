# Conditional direct lowering of the fixed private bridge

This scratch experiment extends the source-associated bridge Core with seven checked status/cleanup branches: Busy, InvalidInput, FrameLimit, reservation error, OutputTooSmall, success and unexpected trap. The independent Core verifier rejects altered branch kind, status or cleanup mode before output. The direct caller-body emitter consumes all thirteen affine operations in order and emits the actual fixed Wasm instructions for each operation. Input-copy completion, result-handling completion and the explicit `space.end` erase to zero bytes at their checked sequencing points; the emitted control code handles empty input and OutputTooSmall without assuming that a byte-copy loop ran. Branch status words come from the checked Core, and the fixed reservation-error or normal cleanup path is selected only after its corresponding cleanup mode is checked.

Unlike the prior fixed-template reconstruction, this emitter does not scan, copy or require `m12_internal_body` or a pre-emitted complete caller. It directly emits the private fixed-profile checks, loops, calls and publication sequence, then assembles the unchanged source-associated worker/adapter base. The separate existing source/target validator checks the whole resulting module against the pinned target. This preserves the prior exact caller bytes, but is not a general CFG or arbitrary K1 Core backend: the supported branches, operations, record shape, capacities, helper calls and memory map are a closed fixture. `m12_internal_emit::emit` remains routed through source-derived Core and this checked lowerer; no low-level source emitter or raw Wasm export is a public authority boundary.

`bridge_plan_test.goose` exercises every branch kind/status/cleanup mutation, every affine operation and range-field mutation, absent/reordered `space.end`, forged source and cross-source proof reuse. The generated caller is also exercised by the existing zero/nonempty, 10,000-wire, output-capacity, alternate-source and injected cleanup-trap oracles. Public ABI/manifest eligibility and M11 remain closed; unexpected traps require discarding the instance and can leave partial payload bytes. Source loans and initialization still depend on the checked closed adapter, fixed runtime/helper contracts and protected nonconcurrent memory. The scope does not establish general source ownership, arbitrary error branches, complete frame/depth, C09, runtime or compile-speed improvement.

The branch Core additionally records an invocation-local origin phase. Busy, invalid and failed frame entry create no invocation resources; a failed reservation exits from the entered-frame phase with no owner or Space. Success and OutputTooSmall split after the returned output loan exists, then independently replay the same output/input/Space/owner/frame cleanup. The trap record represents a poison exit from any phase and deliberately does not assert cleanup. Branch phases are checked logical facts, not runtime authority; final source-target validation remains mandatory.

The trap record's `0xffffffff` status is an internal proof sentinel only. The generated target emits Wasm `unreachable` on an unexpected trap and never publishes that sentinel as a bridge status.
