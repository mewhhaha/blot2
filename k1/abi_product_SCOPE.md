# Private U32 tuple ABI schema and generic target

This experiment recognizes only a source type expression consisting of 2–16 `U32` tuple fields with inline spaces. A lexer-based producer and separate byte-parser/record decoder independently establish the ordered all-U32 fields, 4-byte alignment, 4*n byte size and Plain/Share flags. The private binary record distinguishes field count and type; it is not the canonical complete M10 ABI format. Unknown fields, nesting, comments, newlines and other type forms fail closed.

The linker takes the exact generic identity source and exact tuple type expression from the trusted compiler request. It reconstructs the expected generic dictionary from the independently recognized type, revalidates the generic source and verifies the actual emitted Wasm with the existing independent target checker. Node executes that fixed worker with dictionary sizes for every tuple width. The actual caller program's explicit generic substitution has not been parsed or bound to the requested type expression; runtime dictionary bytes, input initialization, result exclusivity, move/loan authority and memory nonconcurrency remain external preconditions. Numeric schema IDs, flags and hashes alone never confer those authorities.

This is not a real interface/implementation/manifest/certificate linkage, a complete layout engine, complete type/overload registry, C09 work accounting, public K1 ABI or M10 qualification; the policy hash is provisional and public eligibility always false. O0/O2 controls check byte flips in type/schema/dictionary/target, schema truncation, wrong dictionary size/ID, invalid type expressions and actual 2–16 element Wasm copies.
