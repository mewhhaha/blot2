# Private fixed-caller input-copy completeness

`i08_copy_complete.mjs` checks the exact pinned canonical private caller through the existing source-gated caller, guard and descriptor binding checks. It independently matches the complete actual instruction sequence from the input descriptor data load through loop initialization, bound, ingress byte read, destination byte write, unit increment, backedge and the succeeding checked freeze call. For all nine possible counts and six owner blocks it checks that the unit-increment loop covers exactly the `16*count` destination bytes once, that no bytes are read when count is zero, and that all allowed bounded input offsets stay inside ingress and outside the 192-byte pool reservation. This discharges the *copy completeness* part of the previous initialized-input assumption on normal checked execution of this one generated caller: each destination byte comes from its corresponding validated readable ingress byte before freeze.

The result is conditional on the independently run source/target Goose gate, trusted decoder and JS/Wasm intrinsics, bytes unchanged during the initial private snapshot, private nonconcurrent instance, initialized Wasm ingress memory, correctly validated wire bounds, and the separately established real allocator/descriptor helper semantics and owner extent. The proof does not derive live authority from numeric IDs; it does not establish general source loans, untrusted external capabilities, input schema beyond this fixed four-F32 record, public ABI, M11, frame sufficiency, C09 or typed cleanup after traps. Unexpected trap paths do not assert complete initialization and must poison/discard the instance. The unpinned diagnostic is only for negative tests and never grants authority.

Run source gate `m12_helper_source_test.goose` in a fresh artifact directory, then `node "$K1_PATH/i08_copy_complete_test.mjs"`. O0/O2 tests include five type-valid changed-loop mutations rejected by the unpinned diagnostic, hostile input snapshots, and 342 actual aligned count/offset cases that verify every copied byte, ingress immutability and successful owner/frame cleanup. Exhaustive static geometry also covers 8,046 count/block/offset combinations, including unaligned offsets as a conservative superset.

The independent `i08_copy_complete_independent_test.mjs` adds six type-valid loop/freeze mutations and every-byte XOR/truncation controls. Its unpinned mutation diagnostic is test-only.
