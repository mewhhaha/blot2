# Private typed scalar/finite-loop arena bridge

This scratch candidate uses one owned `mixed_core::Tree` node/binding arena for both scalar statements and bounded finite loops in a single U32 -> U32 source declaration. A per-node type vector is derived from the checked tree and is rederived on validation; callers cannot grant authority by supplying type tags. The full original public-shaped source and declared empty effects/resources are retained and independently re-recognized. Original source projects into the arena's function-local spans. Existing independent mixed-source, lexical scope/target, completion, type and checked-arithmetic proof replay is required before accepting a tree. A target is returned only after the existing independent joined decoder checks it against that source-bound tree.

This is a migration seam, not yet the final common typed Core: it reuses the current mixed producer and verifier through a temporary validated adapter, currently has only U32 parameter/result and U32 bindings, and does not accept the full scalar operator set or arbitrary loops. Existing proof rules remain conservative; facts are not carried across a loop backedge without an independently checked rule. There is no general SSA/invariant, ownership/loan or capability authority. Type vector and numeric IDs are internal to this one source owner, not cross-compile provenance.

The caller retains independent immutable expected source, and the tree and source must not be mutated concurrently while checking or emitting. The original public declaration's resource numbers are parsed but not proved. Public admission, M13, ABI, full C09 and compiler/runtime performance are not established. Old dispatch remains untouched and old status/byte compatibility is not claimed for this new candidate. Bool binding work remains a separate scratch source-bound prototype pending its direct loop integration and review.
